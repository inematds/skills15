#15

NotebookLM

economia de tokens19,8 mil ★ em 18/10/2026licença: MIT

O problema

Quando você joga muitos PDFs no Claude, ele lê tudo palavra por palavra e o seu limite de uso acaba rápido.

O que faz

Deixa o Claude comandar o NotebookLM do Google (hoje chamado Gemini Notebook). O Claude cria o caderno, envia os documentos e faz as perguntas; quem lê e analisa é o Google, e a resposta volta com as fontes citadas.

Como funciona

  1. Você instala a ferramenta no computador e entra com a sua conta Google uma vez
  2. O Claude cria um caderno no NotebookLM
  3. Envia os seus arquivos (PDF, links, YouTube, Google Drive)
  4. Faz as perguntas lá dentro; o Gemini lê e responde com base nas suas fontes
  5. A resposta, com as citações, volta para a conversa no Claude

Como instalar

uv tool install "notebooklm-py[browser]" → notebooklm login → notebooklm skill install (ou: npx skills add teng-lin/notebooklm-py). Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

uv tool install "notebooklm-py[browser]"
notebooklm login
notebooklm skill install

Exemplo

Você pede: Crie um caderno com os meus PDFs da pasta Contratos e me dê os três pontos principais.

Volta: O Claude cria o caderno no NotebookLM, envia os PDFs e devolve os três pontos principais com a indicação de qual documento sustenta cada um.

Cuidado

Não é oficial do Google: usa APIs não documentadas que podem mudar e quebrar a qualquer momento, e uso pesado pode ser limitado. Precisa de login com conta Google.

#14

I Have ADHD

respostas57,7 mil ★ em 18/10/2026licença: MIT

O problema

O Claude enrola: escreve três parágrafos antes de dar a resposta que você precisava.

O que faz

Uma skill com 10 regras que obriga o assistente a começar pela ação, numerar os passos e cortar enfeites. Nada de 'Ótima pergunta!' no começo nem 'Espero ter ajudado' no fim.

Como funciona

  1. Você instala o plugin e chama /i-have-adhd (ou deixa ligado sempre)
  2. A resposta começa pela próxima ação: comando, arquivo ou trecho
  3. Tarefas com várias etapas vêm numeradas, listas com no máximo 5 itens
  4. Sem introdução, sem resumo repetido, sem frase de despedida
  5. Termina com um único próximo passo concreto

Como instalar

claude plugin marketplace add ayghri/i-have-adhd → claude plugin install i-have-adhd@i-have-adhd (depois digite /i-have-adhd). Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd

Exemplo

Você pede: Como eu arrumo o meu site que está lento?

Volta: Volta uma lista curta e numerada do que fazer, na ordem, e um único próximo passo no final, sem explicação longa antes.

Cuidado

O nome é só um apelido: não é ferramenta de saúde nem exige diagnóstico. A regra de sempre ligar é opcional (arquivo ~/.claude/.i-have-adhd-always).

#13

Billion Context

economia de tokens1,9 mil ★ em 18/10/2026licença: não identificada pelo GitHub (NOASSERTION)

O problema

Em conversa longa, a cada mensagem o modelo relê tudo desde o início, e isso consome o limite muito rápido.

O que faz

Fica no meio do caminho entre o seu assistente e o modelo e comprime a parte antiga da conversa em resumos detalhados. O próprio modelo decide quando e o que resumir, e pode desfazer o resumo se precisar do detalhe de volta.

Como funciona

  1. Você instala o comando bili e liga o Claude Code por ele
  2. Cada pedido passa por um intermediário (proxy) antes de ir ao modelo
  3. O intermediário dá ao modelo ferramentas para comprimir, descomprimir e buscar no histórico
  4. Trechos antigos viram resumos; o importante fica, o resto sai
  5. Você continua conversando e a compressão acontece por trás

Como instalar

No Claude Code: /plugin marketplace add ranxianglei/billion-context → /plugin install billion-context@billion-context → /billion-context:bili-setup (e reiniciar). Alternativa: npm install -g billion-context --prefix=~/.local e depois bili claude. Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

claude plugin marketplace add ranxianglei/billion-context
claude plugin install billion-context@billion-context

Exemplo

Você pede: Instale o billion-context e abra o Claude Code por ele para eu continuar este projeto na mesma conversa.

Volta: A conversa segue normalmente; as partes antigas são resumidas em segundo plano e o comando /acp mostra quanto do contexto está em uso.

Cuidado

Os números (5 vezes menos tokens, sessões de meses, 174 mil chamadas em 4,5 meses) são do próprio autor, no artigo dele; ninguém de fora mediu. Ele intercepta o tráfego entre o assistente e o modelo (proxy, em alguns modos com certificado próprio), então teste antes de usar em coisa séria.

#12

Find Skills

descoberta35,5 mil ★ em 18/10/2026licença: MIT

O problema

Existem milhares de skills e você não sabe se já tem uma pronta para o que precisa.

O que faz

Uma skill que procura outras skills. Você pergunta em português comum e ela busca no diretório aberto de skills (skills.sh) e devolve as opções com o comando de instalação de cada uma.

Como funciona

  1. Você pergunta se existe skill para alguma tarefa
  2. Ela identifica o assunto e a tarefa
  3. Confere o ranking do skills.sh e roda a busca (npx skills find)
  4. Filtra por qualidade: número de instalações, quem publicou, estrelas
  5. Mostra as opções com o comando para instalar

Como instalar

npx skills add vercel-labs/skills --skill find-skills. Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

npx skills add vercel-labs/skills --skill find-skills

Exemplo

Você pede: Existe uma skill para escrever guias em PDF?

Volta: Volta uma lista de skills encontradas, com quantas instalações cada uma tem, quem publicou e o comando npx skills add para instalar.

Cuidado

Ela só sugere; quem decide instalar é você. A própria skill manda desconfiar de skills com menos de 100 instalações ou de repositórios pequenos.

#11

De-AI Writing

escritapost do Reddit (sem repositório)

O problema

Texto com cara de IA ('situado no coração da cidade, um testemunho da rica herança cultural') faz o leitor desconfiar e parar de ler.

O que faz

Instruções publicadas no Reddit que viram uma skill para reescrever texto tirando as marcas de escrita de IA. A base é a lista 'Signs of AI writing' da Wikipedia, mantida pelo WikiProject AI Cleanup. Quem quer instalar com um comando pode usar o Humanizer (blader/humanizer), que usa a mesma base.

Como funciona

  1. Você copia as instruções do post do Reddit
  2. Cola no Claude e diz 'transforme isso em skill'
  3. Manda o seu texto para a skill
  4. Ela troca as marcas de IA (palavras da moda, travessões em excesso, frases de efeito) por frases diretas
  5. Mostra o que mudou para você desfazer o que não gostar

Como instalar

Não tem repositório: copiar as instruções do post do Reddit, colar no Claude e dizer 'transforme isso em skill'. Alternativa instalável com a mesma base (Humanizer): /plugin marketplace add blader/humanizer → /plugin install humanizer@humanizer.

claude plugin marketplace add blader/humanizer
claude plugin install humanizer@humanizer

Exemplo

Você pede: Reescreva este texto do meu café sem cara de IA: 'Situado no coração da cidade, nosso café é um testemunho da rica herança cultural da região.'

Volta: Algo como 'Nosso café fica na praça principal, num prédio que é padaria desde 1911', com a lista do que foi trocado.

Cuidado

Não há código nem repositório para conferir; o conteúdo do post não foi verificado aqui. A promessa de reduzir a detecção de IA em 70 a 95% é do autor do post. O README do Humanizer, que usa a mesma base, diz o contrário: enganar detector não é objetivo e os detectores ainda marcam a maior parte do texto dele.

#10

Archify

diagramas85,4 mil ★ em 18/10/2026licença: MIT

O problema

Explicar como funciona uma automação, um sistema ou um plano numa reunião, e o cliente só balança a cabeça sem entender.

O que faz

Transforma uma descrição em uma frase (ou um código existente) em um diagrama interativo num único arquivo HTML. Quem recebe clica em cada etapa, segue caminhos e vê o que acontece depois, sem instalar nada.

Como funciona

  1. Você descreve o processo em uma frase (não precisa de código)
  2. O agente monta a estrutura do diagrama
  3. Verificadores embutidos conferem e corrigem a estrutura
  4. Sai um único arquivo HTML que abre no navegador
  5. Você pede ajustes na conversa: 'destaque esse caminho', 'tema claro'

Como instalar

npx skills add tt-a1i/archify -g. Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

npx skills add tt-a1i/archify -g

Exemplo

Você pede: Use o Archify para desenhar como funciona o meu atendimento: o cliente manda mensagem no WhatsApp, o agente responde e, se não souber, passa para um humano.

Volta: Um arquivo HTML com o fluxo desenhado; dá para clicar em cada etapa, ver os detalhes e seguir o caminho de ponta a ponta.

Cuidado

Pode consultar um endereço fixo uma vez por dia só para avisar de atualização (desliga com ARCHIFY_UPDATE_CHECK_DISABLED=1). Serviços pagos de terceiros com o nome não são do projeto.

#9

NanoClaw

assistente31 mil ★ em 18/10/2026licença: MIT

O problema

Ter um assistente de IA pessoal no celular sem entregar a sua vida a um programa enorme que ninguém entende.

O que faz

Um assistente pessoal que você conversa pelo WhatsApp, Telegram, Slack, Discord, iMessage e outros. Ele lembra do que você contou, roda tarefas agendadas e cada agente trabalha isolado num contêiner próprio. Roda sobre o Claude Agent SDK da Anthropic.

Como funciona

  1. Você baixa o projeto e roda o script de instalação
  2. O script instala Node, pnpm e Docker se faltarem e monta o contêiner do agente
  3. Liga o seu primeiro canal (WhatsApp, Telegram, Slack...)
  4. Você manda mensagem com a palavra de chamada (padrão: @Andy)
  5. Ele responde, guarda memória e executa tarefas no horário combinado

Como instalar

git clone https://github.com/nanocoai/nanoclaw.git nanoclaw-v2 → cd nanoclaw-v2 → bash nanoclaw.sh (rodar no terminal, fora de uma sessão do Claude). Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

Exemplo

Você pede: @Andy toda segunda às 8h, junte as notícias de IA da semana e me mande um resumo.

Volta: Toda segunda às 8h chega no seu WhatsApp/Telegram uma mensagem com o resumo das notícias.

Cuidado

É um projeto maior que uma skill: exige Docker e o cadastro da sua credencial da Anthropic. O setup manda diagnósticos anônimos (desliga com NANOCLAW_NO_DIAGNOSTICS=1). A história do acordo com a Docker, do Hacker News e do post do Karpathy não está no README.

#8

CLAUDE.md do Karpathy

regras220 mil ★ em 18/10/2026licença: MIT (declarada no README; o GitHub não detecta arquivo de licença)

O problema

Você pede para o Claude mudar uma linha e ele reescreve metade do projeto e ainda inventa recursos que ninguém pediu.

O que faz

Um único arquivo CLAUDE.md com quatro regras, tiradas das observações de Andrej Karpathy sobre os erros dos modelos ao programar: pensar antes de codar, simplicidade primeiro, mudanças cirúrgicas e execução guiada por objetivo.

Como funciona

  1. Pensar antes de codar: dizer as suposições e perguntar quando estiver em dúvida
  2. Simplicidade primeiro: o mínimo de código que resolve, nada a mais
  3. Mudanças cirúrgicas: mexer só no que foi pedido
  4. Execução guiada por objetivo: transformar o pedido em meta verificável (ex.: um teste que precisa passar)

Como instalar

/plugin marketplace add forrestchang/andrej-karpathy-skills → /plugin install andrej-karpathy-skills@karpathy-skills (ou baixar o CLAUDE.md para a pasta do projeto: curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md). Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

claude plugin marketplace add forrestchang/andrej-karpathy-skills
claude plugin install andrej-karpathy-skills@karpathy-skills

Exemplo

Você pede: Corrija só o erro de digitação no título da página inicial.

Volta: O Claude muda só aquela linha e não mexe no resto; se tiver dúvida, pergunta antes.

Cuidado

Não foi escrito pelo Karpathy: é um arquivo 'inspirado' num post dele, feito por outro autor (forrestchang, hoje na organização multica-ai). O README avisa que deixa o Claude mais cauteloso e um pouco mais lento em tarefas triviais.

#7

HyperFrames

vídeo66,8 mil ★ em 18/10/2026licença: Apache-2.0

O problema

Fazer um vídeo com título animado, música e cortes leva uma hora num editor, e no fim o tempo ainda fica errado.

O que faz

Ferramenta de código aberto da HeyGen que transforma páginas HTML com animações em vídeo MP4. Você descreve o vídeo em palavras e o agente monta, confere e renderiza, com títulos, animações, vídeo de fundo e música.

Como funciona

  1. Você descreve o vídeo em linguagem comum
  2. O agente planeja as cenas e escreve o vídeo como página HTML
  3. Adiciona animações, mídia e música
  4. Confere e mostra uma prévia no navegador
  5. Renderiza: o navegador captura quadro a quadro e o FFmpeg gera o MP4

Como instalar

claude plugin marketplace add heygen-com/hyperframes → claude plugin install hyperframes@hyperframes (depois use /hyperframes:hyperframes). Precisa de Node.js 22+ e FFmpeg. Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

Exemplo

Você pede: Usando o /hyperframes, crie uma abertura de 10 segundos para o meu produto com título aparecendo devagar, vídeo de fundo e música suave.

Volta: Um arquivo MP4 pronto com o título animado, o fundo e a trilha.

Cuidado

Exige Node.js 22+ e FFmpeg instalados. A HeyGen também vende serviços pagos; o HyperFrames em si é aberto e roda local.

#6

Skills do Matt Pocock

código296 mil ★ em 18/10/2026licença: MIT

O problema

O Claude escreve milhares de linhas em minutos e depois você passa dias descobrindo o que quebrou, porque ele começou antes de entender o que você queria.

O que faz

O conjunto de skills que o professor de programação Matt Pocock usa todo dia. Elas atacam quatro problemas: o agente não fez o que você queria, fala demais, o código não funciona e o projeto vira uma bagunça. O /grill-me faz perguntas até o plano ficar claro, o /tdd escreve teste antes do código e o /code-review revisa o próprio trabalho.

Como funciona

  1. Você instala o pacote e roda /setup-matt-pocock-skills uma vez por projeto
  2. Antes de construir, o /grill-me te entrevista até o plano ficar claro
  3. O /tdd escreve o teste primeiro e depois o código que faz passar
  4. O /code-review revisa a mudança antes de você aceitar
  5. Outras, como /diagnosing-bugs e /improve-codebase-architecture, cuidam de erros e da organização

Como instalar

claude plugin install mattpocock-skills@claude-plugins-official → depois rodar /setup-matt-pocock-skills no projeto. Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

claude plugin install mattpocock-skills@claude-plugins-official

Exemplo

Você pede: /grill-me quero fazer uma página de inscrição para o meu curso.

Volta: Em vez de sair programando, o Claude faz uma série de perguntas (quem se inscreve, que dados pedir, o que acontece depois) até o plano ficar fechado.

Cuidado

Feito para quem programa: o setup pergunta qual sistema de tarefas e etiquetas você usa. Não instalar pelo plugin e pelo skills.sh ao mesmo tempo, senão cada skill aparece duas vezes.

#4

Graphify

conhecimento128 mil ★ em 18/10/2026licença: Apache-2.0

O problema

Notas, PDFs, prints, vídeos e código numa mesma pasta, e ninguém sabe o que liga com o quê.

O que faz

Você digita /graphify e ele lê a pasta inteira e monta um mapa (grafo de conhecimento) de como cada coisa se liga. Depois o agente consulta esse mapa em vez de reler todos os arquivos.

Como funciona

  1. Você roda /graphify . na pasta
  2. O código é lido localmente, sem IA e sem sair do computador
  3. Documentos, PDFs, imagens e vídeos passam pelo modelo do seu assistente para extrair o sentido
  4. Cada ligação é marcada como lida direto da fonte ou deduzida
  5. Saem três arquivos: o mapa clicável (graph.html), um relatório e o grafo completo para consultas

Como instalar

uv tool install graphifyy → graphify install (detecta o assistente e registra a skill) → no Claude Code: /graphify . — precisa de Python 3.10+ e uv (ou pipx). Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

uv tool install graphifyy
graphify install

Exemplo

Você pede: /graphify . e depois me diga como o módulo de pagamentos se conecta com o de e-mails.

Volta: Um mapa clicável no navegador mais a resposta com o caminho entre os dois módulos e os arquivos envolvidos.

Cuidado

Atenção ao nome do pacote: graphifyy (com dois y). Arquivos que não são código usam o modelo do assistente (gasta uso). Os '80% menos tokens' do README são da versão paga (Graphify Cloud). A dúvida sobre estrelas e os '75% menos tokens' vêm de comentários citados no vídeo, não do README.

#3

AI Website Cloner

web37 mil ★ em 18/10/2026licença: MIT

O problema

Refazer um site (fontes, cores, layout) pode levar dias de um designer ou desenvolvedor.

O que faz

Um projeto modelo com a skill /clone-website: você passa o endereço e o agente recria o site como um aplicativo Next.js limpo e editável, com as mesmas fontes, cores e estrutura. Parte do site real, não de um print.

Volta: Um projeto Next.js com o site recriado, prints comparando original e cópia e a lista do que ainda ficou diferente.

Cuidado

Clone só site seu ou que você tem permissão. O README proíbe golpe (phishing), se passar por outra marca e copiar design alheio como seu; logos e textos pertencem aos donos.

#2

Anatomy

visual16,1 mil ★ em 18/10/2026licença: MIT

O problema

Você pergunta como algo funciona e recebe um paredão de texto; pergunta de novo e o paredão cresce.

O que faz

Em vez de explicar com texto, constrói um objeto ilustrado e interativo (vista isométrica) cujo funcionamento é a própria ideia. Você mexe com o mouse, aproxima e desmonta peça por peça no navegador. Exemplo da galeria: o motor de foguete Raptor da SpaceX, ligando e depois se desmontando em 11 partes.

Como funciona

  1. Você pede /anatomy e a sua pergunta
  2. O Claude inventa um objeto físico que mostra a ideia funcionando
  3. Monta o objeto com dezenas de peças pequenas e sombreadas, num cartão com título e leitura ao vivo
  4. Confere o próprio trabalho dando zoom em cada encaixe
  5. Entrega uma página HTML (ou SVG) que você abre e explora no navegador

Como instalar

npx skills add wheresryan22/anatomy -g -a claude-code (depois: /anatomy e a pergunta). Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

npx skills add wheresryan22/anatomy -g -a claude-code

Exemplo

Você pede: /anatomy explique como funciona um limitador de requisições, interativo.

Volta: Uma página no navegador com uma máquina ilustrada que mostra o mecanismo funcionando; você passa o mouse e ela se mexe e mostra os números.

Cuidado

É lento de propósito: cada figura leva uma sessão longa (o Raptor leva alguns minutos). Desenha máquinas, instrumentos e objetos, não pessoas nem mapas exatos. O modo 3D ainda é beta.

#1

REA (Reverse Engineer Anything)

engenharia reversa323 mil ★ em 18/10/2026licença: MIT

O problema

Você vê um recurso no aplicativo de outra pessoa e quer no seu, mas não tem o código, então chuta e erra.

O que faz

Conecta o seu agente a ferramentas que examinam um aplicativo pronto sem precisar do código-fonte. O agente descobre como o recurso funciona, mostra as provas de cada conclusão e constrói uma versão parecida no seu projeto.

Como funciona

  1. Você roda o setup, que liga o REA ao seu agente (via MCP)
  2. Pede para investigar um recurso de um aplicativo
  3. O REA examina o aplicativo (programas nativos, apps JavaScript/Electron, .NET, sites) no seu computador
  4. Devolve o que achou com as provas e o que ficou sem resposta
  5. O agente explica o funcionamento e escreve e testa uma versão no seu projeto

Como instalar

npx rea-agents setup (escolher o Claude Code, aprovar as mudanças e reiniciar o agente). Também vale: colar o link no Claude Code e dizer 'instale isso para mim'.

npx rea-agents setup

Exemplo

Você pede: Entenda como funciona a busca no app de Notas, me mostre as provas e construa algo parecido no meu projeto.

Volta: Uma explicação de como a busca funciona por dentro, com os trechos e referências que provam cada ponto, e uma versão parecida implementada e testada no seu projeto.

Cuidado

Só para software que é seu ou que você tem autorização para examinar (pesquisa, ensino, compatibilidade); o README pede uso legal. Análise de programas nativos pode precisar de ferramentas como Hopper, Ghidra ou IDA, e as comerciais exigem licença. Baixe só das fontes oficiais (morluto/rea, rea.tools, pacote npm rea-agents).
