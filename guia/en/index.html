The 15 skills worth it

There are over a million skills out there. These 15 solve real problems: use less of your limit, get straight answers, draw diagrams, make videos, code with a method and look inside any app.

See the 15View on GitHub
In short

skills15 is a free catalog of the 15 AI agent skills (for Claude Code and others) that are most worth it today. For each one you get the problem it solves, how it works inside, the official install command, an example request and a link to the original project. It is for anyone who uses Claude and wants to pick the right skill for today's pain, without installing everything. No coding needed: paste the link into Claude Code and ask it to install it.

What it is

#15

NotebookLM

token savings19.8k ★ on 10/18/2026license: MIT

The problem

When you add lots of PDFs to Claude, it reads every word and your usage limit runs out quickly.

What it does

Lets Claude control Google NotebookLM (now called Gemini Notebook). Claude creates the notebook, uploads the documents, and asks the questions; Google reads and analyzes them, then sends back an answer with cited sources.

How it works

  1. You install the tool on your computer and sign in to your Google account once
  2. Claude creates a notebook in NotebookLM
  3. It uploads your files (PDF, links, YouTube, Google Drive)
  4. It asks questions there; Gemini reads and answers based on your sources
  5. The answer, with citations, returns to the conversation in Claude

How to install

uv tool install "notebooklm-py[browser]" → notebooklm login → notebooklm skill install (or: npx skills add teng-lin/notebooklm-py). You can also paste the link into Claude Code and say “install this for me.”

uv tool install "notebooklm-py[browser]"
notebooklm login
notebooklm skill install

Example

You ask: Create a notebook with the PDFs in my Contracts folder and give me the three main points.

You get: Claude creates the notebook in NotebookLM, uploads the PDFs, and returns the three main points with an indication of which document supports each one.

Caveat

This is not an official Google tool: it uses undocumented APIs that may change and break at any time, and heavy use may be limited. You need to sign in with a Google account.

#14

I Have ADHD

responses57.7k ★ on 10/18/2026license: MIT

The problem

Claude rambles: it writes three paragraphs before giving you the answer you needed.

What it does

A skill with 10 rules that makes the assistant start with the action, number the steps, and cut the fluff. No “Great question!” at the start or “I hope this helps” at the end.

How it works

  1. You install the plugin and run /i-have-adhd (or leave it on all the time)
  2. The answer starts with the next action: a command, file, or snippet
  3. Tasks with several steps are numbered, and lists have no more than 5 items
  4. No introduction, repeated summary, or sign-off
  5. It ends with one clear next step

How to install

claude plugin marketplace add ayghri/i-have-adhd → claude plugin install i-have-adhd@i-have-adhd (then type /i-have-adhd). You can also paste the link into Claude Code and say “install this for me.”

claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd

Example

You ask: How can I fix my slow website?

You get: You get a short numbered list of what to do, in order, with one next step at the end and no long explanation up front.

Caveat

The name is just a nickname: this is not a health tool and does not require a diagnosis. Keeping it on all the time is optional (file ~/.claude/.i-have-adhd-always).

#13

Billion Context

token savings1.9k ★ on 10/18/2026license: not identified by GitHub (NOASSERTION)

The problem

In a long conversation, the model rereads everything from the beginning with every message, using up your limit very quickly.

What it does

It sits between your assistant and the model and compresses older parts of the conversation into detailed summaries. The model decides when and what to summarize, and can undo a summary if it needs the details again.

How it works

  1. You install the bili command and start Claude Code through it
  2. Each request passes through an intermediary (proxy) before reaching the model
  3. The intermediary gives the model tools to compress, expand, and search the history
  4. Old sections become summaries; the important parts stay and the rest is removed
  5. You keep chatting while the compression happens in the background

How to install

In Claude Code: /plugin marketplace add ranxianglei/billion-context → /plugin install billion-context@billion-context → /billion-context:bili-setup (then restart). Alternative: npm install -g billion-context --prefix=~/.local and then bili claude. You can also paste the link into Claude Code and say “install this for me.”

claude plugin marketplace add ranxianglei/billion-context
claude plugin install billion-context@billion-context

Example

You ask: Install billion-context and open Claude Code through it so I can continue this project in the same conversation.

You get: The conversation continues as usual; older parts are summarized in the background, and the /acp command shows how much context is in use.

Caveat

The figures (5 times fewer tokens, sessions lasting months, 174,000 calls in 4.5 months) come from the author’s own article; no one outside has measured them. It intercepts traffic between the assistant and the model (a proxy, sometimes with its own certificate), so test it before using it for important work.

#12

Find Skills

discovery35.5k ★ on 10/18/2026license: MIT

The problem

There are thousands of skills, and you do not know whether one already exists for what you need.

What it does

A skill that finds other skills. Ask in everyday language and it searches the open skills directory (skills.sh), then lists options and each one’s install command.

How it works

  1. You ask whether a skill exists for a task
  2. It identifies the topic and task
  3. It checks the skills.sh ranking and runs a search (npx skills find)
  4. It filters by quality: number of installs, publisher, and stars
  5. It lists the options and the command to install them

How to install

npx skills add vercel-labs/skills --skill find-skills. You can also paste the link into Claude Code and say “install this for me.”

npx skills add vercel-labs/skills --skill find-skills

Example

You ask: Is there a skill for writing PDF guides?

You get: You get a list of skills, how many installs each has, who published them, and the npx skills add command to install each one.

Caveat

It only suggests options; you decide what to install. The skill itself says to be cautious with skills that have fewer than 100 installs or come from small repositories.

#11

De-AI Writing

writingReddit post (no repository)

The problem

Text that sounds like AI (“located in the heart of the city, a testament to its rich cultural heritage”) makes readers suspicious and stop reading.

What it does

Instructions posted on Reddit that can be turned into a skill to rewrite text and remove signs of AI writing. It is based on Wikipedia’s “Signs of AI writing” list, maintained by the WikiProject AI Cleanup. To install something with a command, you can use Humanizer (blader/humanizer), which uses the same source.

How it works

  1. You copy the instructions from the Reddit post
  2. Paste them into Claude and say “turn this into a skill”
  3. Send your text to the skill
  4. It replaces signs of AI writing (trendy words, too many dashes, punchy phrases) with direct wording
  5. It shows what changed so you can undo anything you do not like

How to install

There is no repository: copy the instructions from the Reddit post, paste them into Claude, and say “turn this into a skill.” Installable alternative using the same source (Humanizer): /plugin marketplace add blader/humanizer → /plugin install humanizer@humanizer.

claude plugin marketplace add blader/humanizer
claude plugin install humanizer@humanizer

Example

You ask: Rewrite this text about my café so it does not sound like AI: “Located in the heart of the city, our café is a testament to the region’s rich cultural heritage.”

You get: Something like “Our café is on the main square, in a building that has been a bakery since 1911,” along with a list of what was changed.

Caveat

There is no code or repository to check; the post’s content was not verified here. The claim of reducing AI detection by 70 to 95% comes from the post’s author. The Humanizer README, which uses the same source, says the opposite: evading detectors is not the goal, and detectors still flag most of its text.

#10

Archify

diagrams85.4k ★ on 10/18/2026license: MIT

The problem

You explain how an automation, system, or plan works in a meeting, and the client just nods without understanding.

What it does

Turns a one-sentence description (or existing code) into an interactive diagram in a single HTML file. The person who receives it can click each step, follow paths, and see what happens next, without installing anything.

How it works

  1. You describe the process in one sentence (no code needed)
  2. The agent builds the diagram structure
  3. Built-in checkers review and fix the structure
  4. It creates a single HTML file that opens in a browser
  5. You ask for changes in the conversation: “highlight this path,” “light theme”

How to install

npx skills add tt-a1i/archify -g. You can also paste the link into Claude Code and say “install this for me.”

npx skills add tt-a1i/archify -g

Example

You ask: Use Archify to draw how my customer service works: a customer sends a WhatsApp message, the agent replies, and if it does not know the answer, it hands the conversation to a person.

You get: An HTML file with the workflow drawn out; you can click each step, see the details, and follow the whole path.

Caveat

It may check a fixed address once a day to notify you about updates (turn it off with ARCHIFY_UPDATE_CHECK_DISABLED=1). Third-party paid services with this name are not part of the project.

#9

NanoClaw

assistant31k ★ on 10/18/2026license: MIT

The problem

You want a personal AI assistant on your phone without handing your life over to a huge program no one understands.

What it does

A personal assistant you can talk to through WhatsApp, Telegram, Slack, Discord, iMessage, and more. It remembers what you told it, runs scheduled tasks, and each agent works in its own isolated container. It runs on Anthropic’s Claude Agent SDK.

How it works

  1. You download the project and run the install script
  2. The script installs Node, pnpm, and Docker if needed, and sets up the agent container
  3. You connect your first channel (WhatsApp, Telegram, Slack...)
  4. You send a message with the trigger word (default: @Andy)
  5. It replies, stores memories, and runs tasks at the agreed time

How to install

git clone https://github.com/nanocoai/nanoclaw.git nanoclaw-v2 → cd nanoclaw-v2 → bash nanoclaw.sh (run in the terminal, outside a Claude session). You can also paste the link into Claude Code and say “install this for me.”

Example

You ask: @Andy every Monday at 8 a.m., gather the week’s AI news and send me a summary.

You get: Every Monday at 8 a.m., a message with a news summary arrives on your WhatsApp/Telegram.

Caveat

This is a bigger project than a skill: it requires Docker and your Anthropic credentials. Setup sends anonymous diagnostics (turn them off with NANOCLAW_NO_DIAGNOSTICS=1). The story about the Docker deal, Hacker News, and Karpathy’s post is not in the README.

#8

CLAUDE.md do Karpathy

rules220k ★ on 10/18/2026license: MIT (stated in the README; GitHub detects no license file)

The problem

You ask Claude to change one line and it rewrites half the project and invents features nobody asked for.

What it does

A single CLAUDE.md file with four rules, drawn from Andrej Karpathy’s observations about models’ coding mistakes: think before coding, keep things simple, make focused changes, and work toward a clear goal.

How it works

  1. Think before coding: state assumptions and ask when unsure
  2. Keep it simple: the smallest amount of code that solves the problem, nothing extra
  3. Make focused changes: change only what was requested
  4. Work toward a clear goal: turn the request into a verifiable goal (for example, a test that must pass)

How to install

/plugin marketplace add forrestchang/andrej-karpathy-skills → /plugin install andrej-karpathy-skills@karpathy-skills (or download CLAUDE.md to the project folder: curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md). You can also paste the link into Claude Code and say “install this for me.”

claude plugin marketplace add forrestchang/andrej-karpathy-skills
claude plugin install andrej-karpathy-skills@karpathy-skills

Example

You ask: Fix only the typo in the home page title.

You get: Claude changes only that line and leaves the rest alone; if it is unsure, it asks first.

Caveat

Karpathy did not write it: it is a file “inspired” by one of his posts, made by another author (forrestchang, now in the multica-ai organization). The README warns that it makes Claude more cautious and a little slower on trivial tasks.

#7

HyperFrames

video66.8k ★ on 10/18/2026license: Apache-2.0

The problem

Making a video with an animated title, music, and cuts takes an hour in an editor, and the timing is still wrong at the end.

What it does

An open-source tool from HeyGen that turns animated HTML pages into MP4 video. Describe the video in words and the agent builds, checks, and renders it with titles, animations, background video, and music.

How it works

  1. You describe the video in everyday language
  2. The agent plans the scenes and writes the video as an HTML page
  3. It adds animations, media, and music
  4. It checks the result and shows a preview in the browser
  5. It renders the video: the browser captures each frame and FFmpeg creates the MP4

How to install

claude plugin marketplace add heygen-com/hyperframes → claude plugin install hyperframes@hyperframes (then use /hyperframes:hyperframes). Requires Node.js 22+ and FFmpeg. You can also paste the link into Claude Code and say “install this for me.”

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

Example

You ask: Using /hyperframes, create a 10-second opening for my product with a title that appears slowly, background video, and soft music.

You get: A ready-to-use MP4 file with the animated title, background, and soundtrack.

Caveat

Requires Node.js 22+ and FFmpeg. HeyGen also sells paid services; HyperFrames itself is open source and runs locally.

#6

Skills do Matt Pocock

code296k ★ on 10/18/2026license: MIT

The problem

Claude writes thousands of lines in minutes, then you spend days figuring out what broke because it started before understanding what you wanted.

What it does

The set of skills that programming teacher Matt Pocock uses every day. They tackle four problems: the agent did not do what you wanted, talks too much, writes code that does not work, or makes the project messy. /grill-me asks questions until the plan is clear, /tdd writes a test before the code, and /code-review checks the work.

How it works

  1. You install the package and run /setup-matt-pocock-skills once per project
  2. Before building, /grill-me interviews you until the plan is clear
  3. /tdd writes the test first, then the code that makes it pass
  4. /code-review checks the changes before you accept them
  5. Others, such as /diagnosing-bugs and /improve-codebase-architecture, handle errors and organization

How to install

claude plugin install mattpocock-skills@claude-plugins-official → then run /setup-matt-pocock-skills in the project. You can also paste the link into Claude Code and say “install this for me.”

claude plugin install mattpocock-skills@claude-plugins-official

Example

You ask: /grill-me I want to make a sign-up page for my course.

You get: Instead of jumping into coding, Claude asks a series of questions (who is signing up, what details to ask for, what happens next) until the plan is settled.

Caveat

Made for people who code: setup asks which task and label system you use. Do not install through both the plugin and skills.sh, or each skill will appear twice.

Career Ops

career75.5k ★ on 10/18/2026license: MIT

The problem

Send 50 resumes and 50 cover letters, get two replies.

What it does

A job-search agent that runs on your computer. Paste in a job listing and it checks whether it is still open, scores how well you fit, tailors your resume and cover letter, and drafts answers. You review everything and press Send.

How it works

  1. You install it, add your resume (cv.md), and describe what you are looking for
  2. Paste a job link or its text (/career-ops)
  3. It checks whether the listing is still live
  4. It scores how well your resume matches and tells you when a job is not worth pursuing
  5. It creates a PDF resume, cover letter, and answers; you review and send them

How to install

npx @santifer/career-ops init (creates the career-ops folder; then open Claude Code inside it and use /career-ops). You can also paste the link into Claude Code and say “install this for me.”

npx @santifer/career-ops init

Example

You ask: /career-ops https://empresa.com/vagas/analista-de-dados

You get: A report saying whether the job is still open, how well your resume matches, a tailored PDF resume, and draft answers, all saved on your computer.

Caveat

It never sends an application on its own. Your resume goes to the AI provider you use. The figures (740 jobs, 68 applications, 12 interviews, 1 offer) come from the author.

#4

Graphify

knowledge128k ★ on 10/18/2026license: Apache-2.0

The problem

Notes, PDFs, screenshots, videos, and code are all in one folder, and no one knows how they connect.

What it does

Type /graphify and it reads the whole folder and creates a map (knowledge graph) showing how things connect. Then the agent consults the map instead of rereading every file.

How it works

  1. You run /graphify . in the folder
  2. Code is read locally, without AI and without leaving your computer
  3. Documents, PDFs, images, and videos are sent through your assistant’s model to understand their meaning
  4. Each connection is marked as read directly from a source or inferred
  5. It creates three files: a clickable map (graph.html), a report, and the full graph for searches

How to install

uv tool install graphifyy → graphify install (detects your assistant and registers the skill) → in Claude Code: /graphify . — requires Python 3.10+ and uv (or pipx). You can also paste the link into Claude Code and say “install this for me.”

uv tool install graphifyy
graphify install

Example

You ask: /graphify . and then tell me how the payments module connects to the email module.

You get: A clickable map in the browser, plus an answer showing the path between the two modules and the files involved.

Caveat

Watch the package name: graphifyy (with two y’s). Files that are not code use your assistant’s model (uses your usage allowance). The README’s “80% fewer tokens” claim is for the paid version (Graphify Cloud). The questions about stars and “75% fewer tokens” come from comments mentioned in the video, not the README.

#3

AI Website Cloner

web37k ★ on 10/18/2026license: MIT

The problem

Rebuilding a website (fonts, colors, layout) can take a designer or developer days.

What it does

A project template with the /clone-website skill: give it a website address and the agent recreates the site as a clean, editable Next.js app with the same fonts, colors, and structure. It works from the live site, not a screenshot.

How it works

  1. Map: link the original site’s pages to the project pages
  2. Inspect: examine the site on desktop and mobile, and extract the actual images and fonts
  3. Build: create the components and interactions
  4. Compare: place the original and copy side by side, fix differences, and run a final check

How to install

Paste into Claude Code: “Set up https://github.com/JCodesMore/ai-website-cloner-template as a standalone project in a new folder on my computer...” (prompt from the README), then inside the project: /clone-website https://yoursite.com. Requires Node.js 24+.

Example

You ask: /clone-website https://my-old-website.com

You get: A Next.js project with the recreated website, screenshots comparing the original and copy, and a list of what is still different.

Caveat

Only clone a site you own or have permission to use. The README forbids scams (phishing), impersonating another brand, and claiming someone else’s design as your own; logos and text belong to their owners.

#2

Anatomy

visual16.1k ★ on 10/18/2026license: MIT

The problem

You ask how something works and get a wall of text; ask again, and the wall gets bigger.

What it does

Instead of explaining with text, it builds an illustrated, interactive object (isometric view) that shows the idea in action. Use your mouse to rotate, zoom in, and take it apart piece by piece in the browser. Gallery example: SpaceX’s Raptor rocket engine, turning on and then breaking down into 11 parts.

How it works

  1. You ask /anatomy and your question
  2. Claude invents a physical object that shows the idea in action
  3. It builds the object from dozens of small, shaded parts, in a card with a title and live readout
  4. It checks its own work by zooming in on each connection
  5. It delivers an HTML page (or SVG) that you can open and explore in a browser

How to install

npx skills add wheresryan22/anatomy -g -a claude-code (then: /anatomy and your question). You can also paste the link into Claude Code and say “install this for me.”

npx skills add wheresryan22/anatomy -g -a claude-code

Example

You ask: /anatomy explain how a rate limiter works, interactively.

You get: A browser page with an illustrated machine showing how the mechanism works; move your mouse over it and it moves and shows the numbers.

Caveat

It is slow by design: each illustration takes a long session (the Raptor takes a few minutes). It draws machines, tools, and objects, not people or exact maps. 3D mode is still in beta.

#1

REA (Reverse Engineer Anything)

reverse engineering323k ★ on 10/18/2026license: MIT

The problem

You see a feature in someone else’s app and want it in yours, but you do not have the source code, so you guess and get it wrong.

What it does

Connects your agent to tools that examine a finished app without needing its source code. The agent finds out how a feature works, shows evidence for each conclusion, and builds a similar version in your project.

How it works

  1. You run setup, which connects REA to your agent (via MCP)
  2. You ask it to investigate a feature in an app
  3. REA examines the app (native programs, JavaScript/Electron apps, .NET, websites) on your computer
  4. It returns what it found, with evidence and anything it could not answer
  5. The agent explains how it works and writes and tests a version in your project

How to install

npx rea-agents setup (choose Claude Code, approve the changes, and restart the agent). You can also paste the link into Claude Code and say “install this for me.”

npx rea-agents setup

Example

You ask: Figure out how search works in the Notes app, show me the evidence, and build something similar in my project.

You get: An explanation of how search works inside the app, with snippets and references that support each point, plus a similar version implemented and tested in your project.

Caveat

Only use it with software you own or have permission to examine (for research, teaching, or compatibility); the README asks you to use it legally. Analyzing native programs may require tools such as Hopper, Ghidra, or IDA, and commercial ones require a license. Download only from official sources (morluto/rea, rea.tools, npm package rea-agents).
