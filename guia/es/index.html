#15

NotebookLM

ahorro de tokens19,8 mil ★ al 18/10/2026licencia: MIT

El problema

Cuando le pasas muchos PDF a Claude, los lee palabra por palabra y tu límite de uso se agota rápido.

Qué hace

Permite que Claude controle NotebookLM de Google (ahora llamado Gemini Notebook). Claude crea el cuaderno, envía los documentos y hace las preguntas; quien lee y analiza es Google, y la respuesta vuelve con las fuentes citadas.

Cómo funciona

  1. Instalas la herramienta en el ordenador e inicias sesión con tu cuenta de Google una vez
  2. Claude crea un cuaderno en NotebookLM
  3. Envía tus archivos (PDF, enlaces, YouTube, Google Drive)
  4. Hace las preguntas allí; Gemini lee y responde basándose en tus fuentes
  5. La respuesta, con las citas, vuelve a la conversación en Claude

Cómo instalar

uv tool install "notebooklm-py[browser]" → notebooklm login → notebooklm skill install (o: npx skills add teng-lin/notebooklm-py). También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

uv tool install "notebooklm-py[browser]"
notebooklm login
notebooklm skill install

Ejemplo

Tú pides: Crea un cuaderno con los PDF de mi carpeta Contratos y dame los tres puntos principales.

Recibes: Claude crea el cuaderno en NotebookLM, envía los PDF y devuelve los tres puntos principales indicando qué documento respalda cada uno.

Cuidado

No es oficial de Google: usa APIs no documentadas que pueden cambiar y dejar de funcionar en cualquier momento, y el uso intensivo puede tener límites. Necesitas iniciar sesión con una cuenta de Google.

#14

I Have ADHD

respuestas57,7 mil ★ al 18/10/2026licencia: MIT

El problema

Claude se enrolla: escribe tres párrafos antes de dar la respuesta que necesitabas.

Qué hace

Una skill con 10 reglas que obliga al asistente a empezar por la acción, numerar los pasos y eliminar los adornos. Nada de «¡Buena pregunta!» al principio ni «Espero haberte ayudado» al final.

Cómo funciona

  1. Instalas el plugin y llamas a /i-have-adhd (o lo dejas activado siempre)
  2. La respuesta empieza por la siguiente acción: comando, archivo o fragmento
  3. Las tareas con varios pasos van numeradas y las listas tienen como máximo 5 elementos
  4. Sin introducción, sin resumen repetido, sin despedida
  5. Termina con un único siguiente paso concreto

Cómo instalar

claude plugin marketplace add ayghri/i-have-adhd → claude plugin install i-have-adhd@i-have-adhd (después escribe /i-have-adhd). También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

claude plugin marketplace add ayghri/i-have-adhd
claude plugin install i-have-adhd@i-have-adhd

Ejemplo

Tú pides: ¿Cómo arreglo mi sitio web, que va lento?

Recibes: Devuelve una lista breve y numerada de lo que hay que hacer, en orden, y un único siguiente paso al final, sin una explicación larga antes.

Cuidado

El nombre es solo un apodo: no es una herramienta de salud ni requiere diagnóstico. La regla de mantenerla siempre activada es opcional (archivo ~/.claude/.i-have-adhd-always).

#13

Billion Context

ahorro de tokens1,9 mil ★ al 18/10/2026licencia: no identificada por GitHub (NOASSERTION)

El problema

En una conversación larga, con cada mensaje el modelo vuelve a leer todo desde el principio y el límite se consume muy rápido.

Qué hace

Se sitúa entre tu asistente y el modelo, y comprime la parte antigua de la conversación en resúmenes detallados. El propio modelo decide cuándo y qué resumir, y puede deshacer el resumen si necesita recuperar algún detalle.

Cómo funciona

  1. Instalas el comando bili y conectas Claude Code a través de él
  2. Cada solicitud pasa por un intermediario (proxy) antes de llegar al modelo
  3. El intermediario da al modelo herramientas para comprimir, descomprimir y buscar en el historial
  4. Los fragmentos antiguos se convierten en resúmenes; se conserva lo importante y se elimina el resto
  5. Sigues conversando y la compresión ocurre en segundo plano

Cómo instalar

En Claude Code: /plugin marketplace add ranxianglei/billion-context → /plugin install billion-context@billion-context → /billion-context:bili-setup (y reinicia). Alternativa: npm install -g billion-context --prefix=~/.local y luego bili claude. También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

claude plugin marketplace add ranxianglei/billion-context
claude plugin install billion-context@billion-context

Ejemplo

Tú pides: Instala billion-context y abre Claude Code a través de él para que pueda continuar este proyecto en la misma conversación.

Recibes: La conversación sigue con normalidad; las partes antiguas se resumen en segundo plano y el comando /acp muestra cuánto contexto se está usando.

Cuidado

Las cifras (5 veces menos tokens, sesiones de meses, 174 mil llamadas en 4,5 meses) son del propio autor, en su artículo; nadie externo las ha medido. Intercepta el tráfico entre el asistente y el modelo (proxy, en algunos modos con certificado propio), así que pruébalo antes de usarlo para algo importante.

Find Skills

descubrimiento35,5 mil ★ al 18/10/2026licencia: MIT

El problema

Qué hace

Una skill que busca otras skills. Preguntas en lenguaje corriente y busca en el directorio abierto de skills (skills.sh), y te devuelve opciones con el comando de instalación de cada una.

Cuidado

Solo sugiere; tú decides si instalar. La propia skill recomienda desconfiar de skills con menos de 100 instalaciones o de repositorios pequeños.

#11

De-AI Writing

escriturapost de Reddit (sin repositorio)

El problema

Un texto que parece escrito por IA («situado en el corazón de la ciudad, testimonio de la rica herencia cultural») hace que el lector desconfíe y deje de leer.

Qué hace

Instrucciones publicadas en Reddit que se convierten en una skill para reescribir textos y quitarles los rasgos de escritura de IA. La base es la lista «Signs of AI writing» de Wikipedia, mantenida por WikiProject AI Cleanup. Quien quiera instalarla con un comando puede usar Humanizer (blader/humanizer), que usa la misma base.

Cómo funciona

  1. Copias las instrucciones de la publicación de Reddit
  2. Las pegas en Claude y dices «convierte esto en una skill»
  3. Le das tu texto a la skill
  4. Cambia los rasgos de IA (palabras de moda, exceso de rayas, frases efectistas) por frases directas
  5. Te muestra qué cambió para que puedas deshacer lo que no te guste

Cómo instalar

No tiene repositorio: copia las instrucciones de la publicación de Reddit, pégalas en Claude y di «convierte esto en una skill». Alternativa instalable con la misma base (Humanizer): /plugin marketplace add blader/humanizer → /plugin install humanizer@humanizer.

claude plugin marketplace add blader/humanizer
claude plugin install humanizer@humanizer

Ejemplo

Tú pides: Reescribe este texto de mi cafetería para que no parezca escrito por IA: «Situado en el corazón de la ciudad, nuestro café es testimonio de la rica herencia cultural de la región».

Recibes: Algo como «Nuestra cafetería está en la plaza principal, en un edificio que es panadería desde 1911», junto con la lista de cambios.

Cuidado

No hay código ni repositorio para comprobar; el contenido de la publicación no se verificó aquí. La promesa de reducir la detección de IA entre un 70 y un 95 % es del autor de la publicación. El README de Humanizer, que usa la misma base, dice lo contrario: engañar a los detectores no es el objetivo y estos todavía marcan la mayor parte de su texto.

#10

Archify

diagramas85,4 mil ★ al 18/10/2026licencia: MIT

El problema

Explicas cómo funciona una automatización, un sistema o un plan en una reunión, y el cliente solo asiente sin entender.

Qué hace

Convierte una descripción en una frase (o código existente) en un diagrama interactivo dentro de un único archivo HTML. Quien lo recibe puede hacer clic en cada paso, seguir rutas y ver qué ocurre después, sin instalar nada.

Cómo funciona

  1. Describes el proceso en una frase (no hace falta código)
  2. El agente prepara la estructura del diagrama
  3. Los verificadores integrados revisan y corrigen la estructura
  4. Se genera un único archivo HTML que se abre en el navegador
  5. Pides ajustes en la conversación: «destaca esta ruta», «tema claro»

Cómo instalar

npx skills add tt-a1i/archify -g. También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

npx skills add tt-a1i/archify -g

Ejemplo

Tú pides: Usa Archify para dibujar cómo funciona mi atención al cliente: el cliente escribe por WhatsApp, el agente responde y, si no sabe, se lo pasa a una persona.

Recibes: Un archivo HTML con el flujo dibujado; puedes hacer clic en cada paso, ver los detalles y seguir el recorrido de principio a fin.

Cuidado

Puede consultar una dirección fija una vez al día solo para avisar de actualizaciones (se desactiva con ARCHIFY_UPDATE_CHECK_DISABLED=1). Los servicios de pago de terceros que llevan ese nombre no forman parte del proyecto.

#9

NanoClaw

asistente31 mil ★ al 18/10/2026licencia: MIT

El problema

Tener un asistente personal de IA en el móvil sin entregar tu vida a un programa enorme que nadie entiende.

Qué hace

Un asistente personal con el que hablas por WhatsApp, Telegram, Slack, Discord, iMessage y otros medios. Recuerda lo que le contaste, ejecuta tareas programadas y cada agente trabaja aislado en su propio contenedor. Funciona sobre Claude Agent SDK de Anthropic.

Cómo funciona

  1. Descargas el proyecto y ejecutas el script de instalación
  2. El script instala Node, pnpm y Docker si faltan, y prepara el contenedor del agente
  3. Conectas tu primer canal (WhatsApp, Telegram, Slack...)
  4. Envías un mensaje con la palabra de activación (por defecto: @Andy)
  5. Responde, guarda memoria y ejecuta tareas en el horario acordado

Cómo instalar

git clone https://github.com/nanocoai/nanoclaw.git nanoclaw-v2 → cd nanoclaw-v2 → bash nanoclaw.sh (ejecútalo en la terminal, fuera de una sesión de Claude). También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

Ejemplo

Tú pides: @Andy cada lunes a las 8: reúne las noticias de IA de la semana y envíame un resumen.

Recibes: Cada lunes a las 8 recibes en WhatsApp/Telegram un mensaje con el resumen de las noticias.

Cuidado

Es un proyecto más grande que una skill: requiere Docker y que registres tus credenciales de Anthropic. La configuración envía diagnósticos anónimos (se desactiva con NANOCLAW_NO_DIAGNOSTICS=1). La historia del acuerdo con Docker, de Hacker News y de la publicación de Karpathy no aparece en el README.

#8

CLAUDE.md do Karpathy

reglas220 mil ★ al 18/10/2026licencia: MIT (declarada en el README; GitHub no detecta archivo de licencia)

El problema

Le pides a Claude que cambie una línea y reescribe la mitad del proyecto, además de inventarse funciones que nadie pidió.

Qué hace

Un único archivo CLAUDE.md con cuatro reglas, basadas en las observaciones de Andrej Karpathy sobre los errores de los modelos al programar: pensar antes de escribir código, priorizar la sencillez, hacer cambios quirúrgicos y trabajar guiándose por un objetivo.

Cómo funciona

  1. Pensar antes de escribir código: indicar las suposiciones y preguntar si hay dudas
  2. Priorizar la sencillez: el mínimo código que resuelve el problema, nada más
  3. Cambios quirúrgicos: modificar solo lo que se pidió
  4. Trabajar guiándose por un objetivo: convertir la petición en una meta verificable (por ejemplo, una prueba que debe pasar)

Cómo instalar

/plugin marketplace add forrestchang/andrej-karpathy-skills → /plugin install andrej-karpathy-skills@karpathy-skills (o descarga CLAUDE.md en la carpeta del proyecto: curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md). También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

claude plugin marketplace add forrestchang/andrej-karpathy-skills
claude plugin install andrej-karpathy-skills@karpathy-skills

Ejemplo

Tú pides: Corrige solo el error tipográfico del título de la página de inicio.

Recibes: Claude cambia solo esa línea y no toca el resto; si tiene dudas, pregunta antes.

Cuidado

No lo escribió Karpathy: es un archivo «inspirado» en una publicación suya, creado por otro autor (forrestchang, ahora en la organización multica-ai). El README avisa que hace que Claude sea más prudente y un poco más lento en tareas sencillas.

HyperFrames

vídeo66,8 mil ★ al 18/10/2026licencia: Apache-2.0

El problema

Hacer un vídeo con título animado, música y cortes lleva una hora en un editor, y al final la duración sigue siendo incorrecta.

Qué hace

Herramienta de código abierto de HeyGen que convierte páginas HTML con animaciones en vídeos MP4. Describes el vídeo con palabras y el agente lo prepara, revisa y renderiza, con títulos, animaciones, vídeo de fondo y música.

Cómo funciona

  1. Describes el vídeo en lenguaje corriente
  2. El agente planifica las escenas y escribe el vídeo como una página HTML
  3. Añade animaciones, medios y música
  4. Lo revisa y muestra una vista previa en el navegador
  5. Lo renderiza: el navegador captura cada fotograma y FFmpeg genera el MP4

Cómo instalar

claude plugin marketplace add heygen-com/hyperframes → claude plugin install hyperframes@hyperframes (después usa /hyperframes:hyperframes). Necesita Node.js 22+ y FFmpeg. También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

Ejemplo

Tú pides: Usando /hyperframes, crea una apertura de 10 segundos para mi producto, con el título apareciendo despacio, vídeo de fondo y música suave.

Recibes: Un archivo MP4 listo, con el título animado, el fondo y la música.

Cuidado

Requiere tener instalados Node.js 22+ y FFmpeg. HeyGen también vende servicios de pago; HyperFrames es abierto y funciona localmente.

#6

Skills do Matt Pocock

código296 mil ★ al 18/10/2026licencia: MIT

El problema

Claude escribe miles de líneas en minutos y luego pasas días descubriendo qué se rompió, porque empezó antes de entender lo que querías.

Qué hace

El conjunto de skills que el profesor de programación Matt Pocock usa todos los días. Abordan cuatro problemas: el agente no hizo lo que querías, habla demasiado, el código no funciona y el proyecto se vuelve un caos. /grill-me hace preguntas hasta que el plan queda claro, /tdd escribe una prueba antes del código y /code-review revisa el propio trabajo.

Cómo funciona

  1. Instalas el paquete y ejecutas /setup-matt-pocock-skills una vez por proyecto
  2. Antes de construir, /grill-me te hace preguntas hasta que el plan queda claro
  3. /tdd escribe primero la prueba y luego el código para que pase
  4. /code-review revisa el cambio antes de que lo aceptes
  5. Otras, como /diagnosing-bugs y /improve-codebase-architecture, se ocupan de los errores y la organización

Cómo instalar

claude plugin install mattpocock-skills@claude-plugins-official → después ejecuta /setup-matt-pocock-skills en el proyecto. También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

claude plugin install mattpocock-skills@claude-plugins-official

Ejemplo

Tú pides: /grill-me quiero crear una página de inscripción para mi curso.

Recibes: En vez de ponerse a programar enseguida, Claude te hace una serie de preguntas (quién se inscribe, qué datos pedir, qué ocurre después) hasta dejar el plan cerrado.

Cuidado

Está pensado para quienes programan: la configuración pregunta qué sistema de tareas y etiquetas usas. No lo instales a la vez desde el plugin y skills.sh, porque cada skill aparecerá dos veces.

Graphify

conocimiento128 mil ★ al 18/10/2026licencia: Apache-2.0

El problema

Notas, PDF, capturas, vídeos y código en una misma carpeta, y nadie sabe qué relación hay entre ellos.

Qué hace

Escribes /graphify y lee toda la carpeta para crear un mapa (grafo de conocimiento) de cómo se relaciona cada cosa. Después, el agente consulta ese mapa en vez de volver a leer todos los archivos.

Cómo funciona

  1. Ejecutas /graphify . en la carpeta
  2. El código se lee localmente, sin IA y sin salir del ordenador
  3. Los documentos, PDF, imágenes y vídeos pasan por el modelo de tu asistente para extraer su significado
  4. Cada relación se marca como leída directamente de la fuente o deducida
  5. Se generan tres archivos: el mapa interactivo (graph.html), un informe y el grafo completo para consultas

Cómo instalar

uv tool install graphifyy → graphify install (detecta el asistente y registra la skill) → en Claude Code: /graphify . — necesita Python 3.10+ y uv (o pipx). También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

uv tool install graphifyy
graphify install

Ejemplo

Tú pides: /graphify . y luego dime cómo se conecta el módulo de pagos con el de correos.

Recibes: Un mapa interactivo en el navegador y una respuesta con la ruta entre los dos módulos y los archivos implicados.

Cuidado

Atención al nombre del paquete: graphifyy (con dos y). Los archivos que no son código usan el modelo del asistente (consume uso). El «80 % menos tokens» del README corresponde a la versión de pago (Graphify Cloud). La duda sobre las estrellas y el «75 % menos tokens» proviene de comentarios citados en el vídeo, no del README.

#3

AI Website Cloner

web37 mil ★ al 18/10/2026licencia: MIT

El problema

Rehacer un sitio web (tipografías, colores, diseño) puede llevarle días a un diseñador o desarrollador.

Qué hace

Un proyecto modelo con la skill /clone-website: le das la dirección y el agente reconstruye el sitio como una aplicación Next.js limpia y editable, con las mismas tipografías, colores y estructura. Parte del sitio real, no de una captura.

Cómo funciona

  1. Mapear: relaciona las páginas del sitio original con las del proyecto
  2. Observar: examina el sitio en el ordenador y el móvil, y extrae imágenes y tipografías reales
  3. Construir: crea los componentes y las interacciones
  4. Comparar: coloca el original y la copia uno junto al otro, corrige las diferencias y ejecuta la comprobación final

Cómo instalar

Pega en Claude Code: «Set up https://github.com/JCodesMore/ai-website-cloner-template as a standalone project in a new folder on my computer...» (prompt del README) y después, dentro del proyecto: /clone-website https://seusite.com. Necesita Node.js 24+.

Ejemplo

Tú pides: /clone-website https://meusite-antigo.com.br

Recibes: Un proyecto Next.js con el sitio reconstruido, capturas que comparan el original y la copia, y una lista de lo que aún es diferente.

Cuidado

#2

Anatomy

visual16,1 mil ★ al 18/10/2026licencia: MIT

El problema

Preguntas cómo funciona algo y recibes un bloque enorme de texto; vuelves a preguntar y el bloque crece.

Qué hace

En vez de explicarlo con texto, construye un objeto ilustrado e interactivo (vista isométrica) cuyo funcionamiento muestra la idea. Puedes moverlo con el ratón, acercarte y desmontarlo pieza por pieza en el navegador. Ejemplo de la galería: el motor de cohete Raptor de SpaceX, que se enciende y luego se desmonta en 11 partes.

Cómo funciona

  1. Pides /anatomy y haces tu pregunta
  2. Claude inventa un objeto físico que muestra la idea en funcionamiento
  3. Construye el objeto con decenas de piezas pequeñas y sombreadas, en una tarjeta con título y lectura en directo
  4. Revisa su propio trabajo ampliando cada unión
  5. Entrega una página HTML (o SVG) que abres y exploras en el navegador

Cómo instalar

npx skills add wheresryan22/anatomy -g -a claude-code (después: /anatomy y la pregunta). También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

npx skills add wheresryan22/anatomy -g -a claude-code

Ejemplo

Tú pides: /anatomy explica de forma interactiva cómo funciona un limitador de solicitudes.

Recibes: Una página en el navegador con una máquina ilustrada que muestra el mecanismo; pasas el ratón por encima y se mueve y muestra los números.

Cuidado

Es lento a propósito: cada figura requiere una sesión larga (el Raptor tarda unos minutos). Dibuja máquinas, instrumentos y objetos, no personas ni mapas exactos. El modo 3D aún está en beta.

#1

REA (Reverse Engineer Anything)

ingeniería inversa323 mil ★ al 18/10/2026licencia: MIT

El problema

Ves una función en la aplicación de otra persona y la quieres en la tuya, pero no tienes el código, así que improvisas y te equivocas.

Qué hace

Conecta tu agente con herramientas que examinan una aplicación terminada sin necesitar el código fuente. El agente descubre cómo funciona la función, muestra pruebas de cada conclusión y construye una versión parecida en tu proyecto.

Cómo funciona

  1. Ejecutas la configuración, que conecta REA con tu agente (vía MCP)
  2. Pides que investigue una función de una aplicación
  3. REA examina la aplicación (programas nativos, apps JavaScript/Electron, .NET y sitios web) en tu ordenador
  4. Devuelve lo que encontró, con pruebas y lo que quedó sin respuesta
  5. El agente explica cómo funciona y escribe y prueba una versión en tu proyecto

Cómo instalar

npx rea-agents setup (elige Claude Code, aprueba los cambios y reinicia el agente). También puedes pegar el enlace en Claude Code y decir «instala esto por mí».

npx rea-agents setup

Ejemplo

Tú pides: Entiende cómo funciona la búsqueda en la app de Notas, muéstrame las pruebas y construye algo parecido en mi proyecto.

Recibes: Una explicación de cómo funciona la búsqueda por dentro, con los fragmentos y referencias que prueban cada punto, y una versión parecida implementada y probada en tu proyecto.

Cuidado

Solo para software tuyo o que tengas autorización para examinar (investigación, enseñanza o compatibilidad); el README pide un uso legal. Analizar programas nativos puede requerir herramientas como Hopper, Ghidra o IDA, y las versiones comerciales necesitan licencia. Descarga solo de fuentes oficiales (morluto/rea, rea.tools y el paquete npm rea-agents).
